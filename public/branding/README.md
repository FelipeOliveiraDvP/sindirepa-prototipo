# Assets de marca — Apura

Fonte canônica: `docs/geral/marca/apura-manual-da-marca.pdf` (guia: `docs/geral/05-marca.md`).

Coloque aqui (quando disponíveis):

| Arquivo | Uso |
|---|---|
| `logo-horizontal.png` (+ svg) | cabeçalhos, site, orçamentos, assinatura — principal |
| `logo-vertical.png` | capas, fachada, redes sociais, materiais quadrados |
| `simbolo.png` (+ favicon) | avatar, ícone de app, favicon, carimbos |
| `logo-negativa.png` | sempre sobre Petróleo ou fundo escuro |
| `og.png` | og:image social |

Tamanhos mínimos e área de proteção: ver `docs/geral/05-marca.md`.
